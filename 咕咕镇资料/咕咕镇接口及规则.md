## 1. 入口与认证

### 1.1 进入流程（GET 跳转链）
```
bbs.kfpromax.com/fyg_sjcdwj.php?go=play&xl=2   (xl=2 咕咕镇 / xl=1 咕咕线2)
    → www.momozhen.com/next.php                  (进入确认页, 按钮"进入咕咕镇")
    → www.momozhen.com/fyg_index.php             (游戏主页)
```

### 1.2 认证 Cookie（咕咕镇独立体系）
```
fyg2019_gameuid=768869         用户ID（=论坛 uid）
fyg2019_gamepw=4ca7767f...     "游戏密码"（哈希值）
fyg2019_endtime=1785909306     过期时间戳
fyg2019_logme=1                登录标记
PHPSESSID=e5mcsoin...          游戏会话
```
- **cookie 有效期约 1 天**；论坛侧重新登录会使旧 cookie 失效
- 已登录判定：页面含用户名（如 `yeybsghhz`）

### 1.2b safeid 令牌提取（slack 源码验证）
- **safeid 从 `fyg_index.php` 页面提取**：正则 `&safeid=([^"]+)"` 匹配第一个
- 每个用户/会话固定（实测页面内统一值 `737f26`）
- 所有 `fyg_click.php` / `fyg_v_intel.php` 动作必须携带

### 1.3 登录方式
| 方式 | 接口 | 说明 |
|------|------|------|
| 普通登录 | GET `fyg_index.php` | 论坛 cookie 有效时自动建立会话（经入口跳转链） |
| 密钥登录 | POST `fyg_llpw_li.php` `xemi=<密钥>` | 密钥 7 天有效，权限受限 |

### 1.4 密钥管理（`fyg_llpw.php` 页面）
| 动作 | 接口 |
|------|------|
| 生成新密钥 | POST `fyg_llpw_c.php` `iu=1` |
| 密钥延期7天 | POST `fyg_llpw_c.php` `iu=2` |
| 允许商店 | POST `fyg_llpw_c.php` `iu=3` |
| 禁止商店 | POST `fyg_llpw_c.php` `iu=4` |
- 密钥登录限制：不能买星晶 / 不能把红装丢沙滩 / 不能熔炼销毁红装

### 1.5 退出
```
GET fyg_login.php?m=out   → 清空 cookie → 跳转登录页
```

## 3. 核心接口

### 3.1 数据读取：`fyg_read.php`（POST）
```
Content-Type: application/x-www-form-urlencoded
Body: f=<区块ID> [&id=xx &ca=xx &zid=xx]
```
| f 值 | 内容 |
|------|------|
| `f=1` | **沙滩装备列表**（stall；空沙滩返回空字符串） |
| `f=2` | **仓库列表**（stbp） |
| `f=3` | 锻造区/角色卡片（宝石工坊 cding） |
| `f=5` | **光环天赋区**（卡片装备页 eqbp(5)） |
| `f=6` | **我的装备列表**（eqmy） |
| `f=7` | 武器装备区（eqbp(1)） |
| `f=8` | 角色卡片区（eqbp(2)；12 角色卡列表，点卡进入加点 `xxcard(zid)`） |
| `f=9` | 角色卡片列表（卡片装备页 cding） |
| `f=10` | **翻牌区**（12张角色牌，gifsall） |
| `f=12` | **战场状态/出击列表**（pklist） |
| `f=18&zid=` | **角色卡详情+加点界面**（xxcard；含六维输入框/总属性点/今日可修改次数/升级按钮） |
| `f=19` | 许愿池内容（`YYYY#MMDD#...` 串，24 字段） |
| `f=20&id=&ca=` | **装备/物品详情**（zbtip；**ca=4=沙滩、ca=3=仓库、ca=2=仓库护身符、ca=1=饰品栏护身符**；弹窗含左右对比"所选 vs 当前同部位"+操作按钮） |
| `f=21` | 工坊收菜区（rgamd） |
| `f=22` | 角色卡选择区（bssc，`?eid=` 相关） |
| `f=23` | 争夺等级区（eqbp(4)） |
| `f=24&id=` | 装备卡详情（uucard） |
| `f=25` | 战斗记录（争夺战场页，pklog） |

**f=20 详情弹窗结构（实测 2026-08-06）：**
- 左列 = 所选装备（属性+颜色），右列 = 当前同部位装备（对比）
- 操作按钮按 ca 不同：
  - `ca=3` 仓库：`穿上装备`(puton→c=3) / `丢弃装备`(stdel→c=7) / （若可熔炼）`熔炼该装备为护身符`(pirl→c=9+yz)
  - `ca=4` 沙滩：`放入仓库`(stpick→c=1)
  - `ca=2` 仓库护身符：`强化`(6万贝壳) / `放入我的饰品栏`(puto→c=22) / `销毁该护身符`(pirl→c=9)
  - `ca=1` 饰品栏护身符：`放入仓库 (将不会起效)`(puti→c=21)
- 熔炼资格：词条总值约 ≥410%（样本 406%不可熔 / 425%可熔）**且品质 ≥稀有**（2026-08-10 实测：品质数字 ≥3，418% 品质2不可熔，返回"至少需要稀有级别的装备才可以熔炼"），与词条颜色/神秘属性无关；**熔炼产物固定 = 星铜苹果护身符 随机属性+N**

**2026-08-06 实测补充：**
- `c=1` 拾取：**重复拾取**返回 `卡片不存在。`（实际装备已进仓库，属正常）；正确流程是 `f=20&id=<沙滩id>&ca=4` 打开详情弹窗 → 弹窗内"放入仓库"按钮 `stpick(id)`；沙滩 id 与 zbtip 的 id 一致
- `c=3` 穿戴（puton）：成功返回 `已装备！`；同部位替换（旧装备回仓库）；装备详情弹窗 `f=20&ca=3` 内"穿上装备"按钮触发
- `c=7` 丢弃（stdel）：成功返回 `已将装备丢弃到沙滩，在它从沙滩上消失前，仍可以捡回。`（**可逆**，装备出现在沙滩 24h 内可 `c=1` 捡回）
- `c=9` 熔炼（pirl）：**成功返回新护身符 id**（纯数字），页面 `zbtip(新id,'2')` 显示护身符详情（**ca=2 = 护身符**）；`yz` = **固定防误操作码 124**（弹窗 input `#pirlyz`，placeholder "输入数字124避免误操作"）；**熔炼资格 = 词条总值约 ≥410% 且装备品质 ≥稀有（品质数字 ≥3，icon 文件名 zXXXX_N.gif 的 N）**（2026-08-10 实测：品质3灵光袍430%✅/品质5陨铁重剑486%✅/品质2探险者之剑404%❌返回"至少需要稀有级别的装备才可以熔炼"）；**熔炼结果固定 = "星铜苹果护身符 随机属性+N"**（与装备品质/总值无关，灵光袍→智力+2、陨铁重剑→力量+2、饮血魔剑→敏捷+2）；**神秘装/橙装熔炼 = 巨亏（神秘属性消失），永不熔炼**；被熔炼装备消失
- `c=12` 强制刷新：**消耗 1 个随机装备箱**（it004），沙滩刷新 10 件新装备；**原有装备不清除**；**重置自然刷新计时**（22 小时）；成功返回 `ok`（页面 reload）
- `c=20` 清理（sttz）：成功返回 `沙滩上N件装备被回收利用,获得材料 蓝锻造石 x N 绿锻造石 x N`（示例：10 件 → 蓝×22 绿×1）；**沙滩装备全部回收为锻造石**（不可逆）
- `c=30` 工坊：收工后**自动重新开工**；开工中重复调用返回 `工作至少8小时后才能下班`（开工最短 8 小时）
- `c=18` 许愿：返回格式如 `生命值强化 +1! 生命值强化 +1! 附加魔法伤害 +1!`（每次一项，3 次许愿 3 行）

**护身符详情（`f=20&id=<护身符id>&ca=2`）操作接口：**
- "护身符在'我的饰品'栏中即生效，无需装备"
- **强化**：消耗 6 万贝壳，增强或增加一条随机属性（百分比属性单次强化可能 <1% 只加隐藏分）
- **放入我的饰品栏**（使其产生效果）/ **销毁该护身符**
- 示例：`星铜苹果护身符 敏捷 +2点`（饮血魔剑 425% 熔炼所得）

**护身符佩戴/摘下/存储（2026-08-10 完整实测）⭐⭐：**
```
佩戴：puto → c=22&id=<仓库护身符id>   （返回 ok，护身符移入饰品栏）
摘下：puti → c=21&id=<饰品栏护身符id> （返回 ok，护身符移回仓库）
详情：仓库 f=20&ca=2  /  饰品栏 f=20&ca=1
```
- **未佩戴护身符存在仓库 = 占仓库格**（35 格容量含护身符）
- **佩戴后移入"我的饰品"栏（fyg_equip.php 页面底部）= 不占仓库格**，属性生效
- **饰品栏 8 槽**，同类属性叠加（2 个智力+2 = 智力+4）
- ⚠️ **护身符 id 在佩戴/摘下时变化**（实测 14707979 → 15809795 佩戴 → 14708020 回仓）→ 脚本需每次佩戴/摘下后重新获取 id
- 佩戴中护身符按钮：`zbtip('<id>','1')`（ca=1）；摘下按钮文字"放入仓库 (将不会起效)"

### 3.2c 加点系统（角色六维，2026-08-10 完整实测）⭐⭐

**入口：** `fyg_equip.php` → "角色卡片" tab（eqbp(2)→f=8 角色卡列表）→ 点角色卡 `xxcard(zid)` → `f=18&zid=<角色id>`

**角色卡列表（f=8，12 角色）：** 每卡显示：名称（出战中）/等级（如 800+8%）/技能位/总属性点/经验条；`xxcard(zid)` 进入详情，zid 从 3000 递增（舞=3000、默=3001...）

**加点界面（f=18&zid=）数据：**
```
Lv.800 角色等级          自由分配点数(6+级别*3)，最大升级上限 900 级
8%  卡片品质            额外自由分配点数 = 基础点 × 品质%
4   卡片技能位           角色可佩戴天赋技能上限（光环天赋处修改）
358 角色技能成长点数      部分角色有效，点数所有角色通用
可分配点(剩余) / 总属性点(2598) / 已分配点 / 今日可修改次数(10)
六维输入框：力量(sjll)/敏捷(sjmj)/智力(sjzl)/体魄(sjtp)/精神(sjjs)/意志(sjyz)
```

**⭐ 总属性点公式（2026-08-10 实测推导）：**
```
总属性点 = (6 + 角色等级×3) × (1 + 品质%)
例：舞 Lv.800 品质8% → (6+2400) × 1.08 = 2598.48 → 2598 ✓
```

**六维效果（每点，tooltip 实测）：**
| 属性 | 每点效果 |
|------|---------|
| 力量 | +10 基础物理攻击力 |
| 敏捷 | +3 基础速度 +1 暴击几率 |
| 智力 | +10 基础魔法攻击力 +1 技能几率 |
| 体魄 | +1 物理防御 +35 生命值 |
| 精神 | +65 能量护盾 +0.5 物防 +0.5 魔防 |
| 意志 | +1 魔法防御 +35 生命值 |

**加点规则（statainput 源码）：**
- **单项上限 = 总属性点 × 60%**（`Math.round(zuida*0.6)`，进度条基准）
- 已分配 = 六维之和；可分配 = 总属性点 - 已分配（负值提示"超出最大值，请修改"）
- **今日可修改次数 10**（超限需等明天）

## 4. 游戏规则（抓包确认 + 帖子知识点）

### 4.1 争夺战场（fyg_pk.php）
- **攻击玩家**：胜利 狗牌+1、进度+3%；失败 进度-3%
- **攻击野怪**：胜利 狗牌+1、进度+1%；失败 进度-1%
- 每日需 **3 枚狗牌** 才能翻牌（2025-01 后）；胜利都得 1 狗牌
- 页面数据：段位/进度%/今日狗牌/今日出击次数/连胜/连败
- **100 回合平局不计次数**（无收益）
- PVP 特殊消息："随机对手近日无胜场，不计出击次数，请重试" / "随机匹配轮空或对手段位改变...本次不消耗体力"
- **防守全败不掉进度**（可只打进攻）

**掉段机制（2026-08-06 实测确认）⭐：**
- 段位进度降至 **0%** → 触发降级（CCC→CC），并：
  - **自动送 1 枚狗牌**
  - 段位进度重置为 **90%**
  - 连胜/连败计数清零
- 掉段后野怪等级大幅下降（实测：CCC 段野怪 Lv.38 → CC 段 Lv.10），可轻松取胜回段
- 与"升段 +10% 进度、掉段 →90%"和"A 段以下掉段自动给 1 狗牌"两条帖子规则吻合

**升段机制（2026-08-06 实测确认）⭐：**
- **5 连胜直接升段**（无需等进度 100%）：CC 连胜 5 场 → CCC，进度重置 **10%**（升段 +10%），连胜/连败清零，狗牌保留
- 升段后**野怪等级暴涨**（实测：Lv.11 → Lv.36），若装备不足会立刻连败掉回原段

**⚠️ 低段位瓶颈（2026-08-06 打满 20 出击实测）⭐：**
- **CCC 段是当前装备瓶颈**：野怪 Lv.36《绝对底线》反伤（物/法减伤 90%），需**绝伤属性**才能打；打不过 → -1%/场
- **PVP 在低段位轮空**：连续 4 次"随机对手近日无胜场，不计出击次数"→ 升段只能靠 5 连胜打野
- **CC ↔ CCC 横跳死循环**：CC 野怪 Lv.11 稳赢 5 连胜升 CCC → CCC 野怪 Lv.36 必败掉回 CC → 循环
- 升到 B 段（商店开放）需要：提升装备（堆绝伤）突破 CCC 段，或等 PVP 匹配到人
- 打满 20 次出击：今日共得 **12 狗牌**（20 出击 = 12 胜 8 败，胜率 60%）
- **上限消息复测**：第 21 次出击返回 `今日已主动出击20次，达到上限，请明日再出击`（31 字节）

### 4.2 翻牌（主页 fyg_index.php）
