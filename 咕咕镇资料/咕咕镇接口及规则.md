## 1. 入口与认证

### 1.1 进入流程（GET 跳转链）
```
bbs.kfpromax.com/fyg_sjcdwj.php?go=play&xl=2   (xl=2 咕咕镇 / xl=1 咕咕线2)
    → www.momozhen.com/next.php                  (进入确认页, 按钮"进入咕咕镇")
    → www.momozhen.com/fyg_index.php             (游戏主页)
```

### 1.2 认证 Cookie（咕咕镇独立体系）
```
fyg2019_gameuid=768869         用户ID（=论坛 uid）
fyg2019_gamepw=4ca7767f...     "游戏密码"（哈希值）
fyg2019_endtime=1785909306     过期时间戳
fyg2019_logme=1                登录标记
PHPSESSID=e5mcsoin...          游戏会话
```
- **cookie 有效期约 1 天**；论坛侧重新登录会使旧 cookie 失效
- 已登录判定：页面含用户名（如 `yeybsghhz`）

### 1.2b safeid 令牌提取（slack 源码验证）
- **safeid 从 `fyg_index.php` 页面提取**：正则 `&safeid=([^"]+)"` 匹配第一个
- 每个用户/会话固定（实测页面内统一值 `737f26`）
- 所有 `fyg_click.php` / `fyg_v_intel.php` 动作必须携带

### 1.3 登录方式
| 方式 | 接口 | 说明 |
|------|------|------|
| 普通登录 | GET `fyg_index.php` | 论坛 cookie 有效时自动建立会话（经入口跳转链） |
| 密钥登录 | POST `fyg_llpw_li.php` `xemi=<密钥>` | 密钥 7 天有效，权限受限 |

### 1.4 密钥管理（`fyg_llpw.php` 页面）
| 动作 | 接口 |
|------|------|
| 生成新密钥 | POST `fyg_llpw_c.php` `iu=1` |
| 密钥延期7天 | POST `fyg_llpw_c.php` `iu=2` |
| 允许商店 | POST `fyg_llpw_c.php` `iu=3` |
| 禁止商店 | POST `fyg_llpw_c.php` `iu=4` |
- 密钥登录限制：不能买星晶 / 不能把红装丢沙滩 / 不能熔炼销毁红装

### 1.5 退出
```
GET fyg_login.php?m=out   → 清空 cookie → 跳转登录页
```

### 3.4 出击：`fyg_v_intel.php`（POST）⭐⭐核心
```
Body: id=<1|2>&safeid=<令牌>
  id=1 = 打野（攻击野怪）
  id=2 = 打人（攻击玩家）
```
- **直接执行攻击**（实测：调用一次出击次数 +1，返回值 = 完整战斗战报，约 116KB）
- 战报含：双方属性对比（生命/护盾/六维/天赋）、每回合伤害明细
- 胜利/失败结果反映在 `fyg_read.php f=12` 的段位进度与狗牌数变化
- 注意：**无二次确认**，脚本调用即出击（每击消耗 1 体力）

**战报胜负判定（slack 源码验证）：**
```
"<用户名> 获得了胜利！"        → 胜利
"双方同归于尽！本场不计入胜负场次" → 平局（不消耗次数）
其他                            → 失败
```
- 平局时 `fyg_v_intel.php` 返回会含"本场不计入"字样
- "请重试"（轮空/无胜场对手）→ 不计次数，可循环重打

**⚠️ 出击返回的 5 种类型（全部实测确认 2026-08-05）：**

| 返回特征 | 含义 | 是否计次数 | 示例 |
|---------|------|-----------|------|
| 含 `"<用户名> 获得了胜利！"` | 胜利（完整战报 50-68KB） | ✅ | 打野 Lv.12 全胜 |
| 含 `"双方同归于尽"` | 平局 | ❌ 不计 | - |
| 完整 HTML 战报但 <15KB（无胜负字样） | 快速结束（碾压/被碾压） | ✅ | 打 Lv.38 野怪 6-14KB |
| `<h2>随机对手近日无胜场，不计出击次数，请重试</h2>` | PVP 轮空（对方无近期胜利） | ❌ 不计 | CC 段人少常见 |
| `<h2>今日已主动出击20次，达到上限，请明日再出击</h2>` | **出击次数达上限**（20次/日） | - | 打满 20 次后 |

**战报体积规律**：正常战斗 50-68KB；碾压局（我方秒杀）6-14KB；特殊消息 29-31 字节。
**实战记录**：打野 Lv.12 连战全胜；Lv.38 野怪为碾压局（6-14KB 短战报）。

**段位/狗牌解析（f=12 返回，slack 源码验证）：**
```
段位:  regex r'font-weight:900;">(.*?)</span><br>当前所在段位'
狗牌:  regex r'font-weight:700;">(.*?)</span><br>今日获得狗牌'  取 "N /" 的 N
```

## 4. 游戏规则（抓包确认 + 帖子知识点）

### 4.1 争夺战场（fyg_pk.php）
- **攻击玩家**：胜利 狗牌+1、进度+3%；失败 进度-3%
- **攻击野怪**：胜利 狗牌+1、进度+1%；失败 进度-1%
- 每日需 **3 枚狗牌** 才能翻牌（2025-01 后）；胜利都得 1 狗牌
- 页面数据：段位/进度%/今日狗牌/今日出击次数/连胜/连败
- **100 回合平局不计次数**（无收益）
- PVP 特殊消息："随机对手近日无胜场，不计出击次数，请重试" / "随机匹配轮空或对手段位改变...本次不消耗体力"
- **防守全败不掉进度**（可只打进攻）

### 4.2 翻牌（主页 fyg_index.php）
- **12 张牌** = 4 色（幸运/稀有/史诗/传说），每色 3 张 → 翻出同色 3 张出对应奖励
- 翻牌动作：`giftop(id)` → `c=8&id=<1-12>`（id 从 1 递增，从左到右）
- **翻牌透视（slack 源码验证）**：`f=10` 返回含 `是"(幸运|稀有|史诗|传说)"` 文本（若开启透视）→ 可按透视决定翻哪张
- **翻牌结果解析**：f=10 返回的按钮文本（`//button[contains(@class,'fyg_lh60')]`）累计各色张数
- **翻牌策略**：某色 >1 张时追求保底（2幸运→保底翻完）；2传说→无脑翻
- "获取额外奖励" = `c=13&id=1`（消耗 1 药水再领奖励）；`c=13&id=2` = 消耗 2 药水**重置今日狗牌和翻牌**（同时刷新出击数）

### 4.3 宝石工坊（fyg_gem.php）
- 收工统计收益：`c=30`（cgamd）
- 4 栏：贝壳/随机装备箱/灵魂药水(废弃)/宝石原石
- 开工/领取：读取 `f=21` / `f=3`

### 4.4 沙滩（fyg_beach.php）
- 装备保留 **24 小时**；"清理沙滩"=`c=20` 回收锻造石；"强制刷新"=`c=12` 消耗随机装备箱
- 仓库空格：背包上限

### 4.5 许愿池（fyg_wish.php）
- 许愿：`xy_n(cn,id)` → `c=18&id=<次数>`
