### 3.3 装备属性格式
- `生命偷取 +31.7% 129%`（基础值 + 百分比加成）
- `附加物防 +386.7 132%`
- `[神秘属性]xxx`（如"削弱对方40%回血回盾"）
- 装备数值公式：**装备等级 × 词条百分比**（简单乘算）
- 橙装 = 词条总值 516%-585% 之间

### 3.4 PVP 匹配消息文本（脚本判断用）
- `随机对手近日无胜场，不计出击次数，请重试`（轮空，不计次数，可循环重打）
- `随机匹配轮空或对手段位改变，请重新点击攻击其他玩家。本次不消耗体力。`
- 段位低/人少时 PVP 容易轮空死循环
- **打野、打人（非轮空）都计入出击次数**（2026-08-06 实测：打人失败后 0/1→0/2）

### 3.5 战斗记录 `f=25`（脚本检测被攻击用，2026-08-06 实测）
- **只记录 PVP（打人/被打）**，打野不产生记录
- 返回 HTML 每行一条：`今天 X时 | 攻/被攻 | 胜/败 | [对手]名 | Lv.X 职业 | 空`
- 用途：检测**是否被其他玩家攻击**（防御全败不掉进度 → 可只打进攻不管防守，但被攻击记录可统计）
- 页面加载自动调用（`pklog()`），无需手动点击

## 4. 自动化决策规则（写智能逻辑用）

### 4.1 日常 2 分钟流程（可脚本化）
1. **宝石工坊**：开工→领取→开工（每日收益）
2. **道具工坊**：日限 10w 贝壳
3. **我的沙滩**：清理沙滩，黄红装备留着（可拆成饰品）
4. **争夺战场**：攻击玩家点满 20 次出击
5. **翻牌子**（最左个人信息）：3 张相同颜色牌出奖励

### 4.2 出击策略
- **出击时间**：早上 8 点前出击胜率高（多帖印证）；"S 大段走位大于努力"
- **打人收益 > 打野**：打人即便失败也有幻影经验/成长（2026-08-06 实测：失败不掉狗牌、进度 -3%，仍计出击）
- **100 回合平局不计次数**；A 段以下掉段自动给 1 狗牌
- **防守全败不掉进度** → 脚本可只打进攻不管防守
- 出击次数逻辑：PVP 胜利/失败都 ±3% 进度（2025-01 后）；升段 +10% 进度、掉段 →90%

### 4.3 翻牌与狗牌
- 翻牌需 **3 张狗牌**（曾临时取消）；PVP 和 PVE 胜利都得 1 狗牌
- 翻牌方式：从左依次向右翻，3 张相同颜色出奖励

### 4.4 打野机制
- **野怪动态等级**：受玩家涌入/降级影响（BB 段史莱姆 150-170，BBB 230-300）
- **不同角色对应不同野怪**，强度不同（舞/梦/希差异大）
- 平局不计次数（可利用：稳赢/平局打法稳定上分）
- 打野角色排行：T0 梦/希，T1 雅/薇，下水道冥

### 4.5 沙滩装备收取/清理规则 ⭐可配置
> 依据：装备数值公式 = 等级×词条%，橙装=词条总值516-585%，分解出+5看等级（250以下无价值）
> **已实测验证**（2026-08-05）：收取/穿戴/清理全流程跑通

**沙滩装备数据格式（实测 `f=1` 返回）**：每件 = 等级 + 名称 + 星级(`icon-star` 数) + 词条列表（名称+数值+百分比，颜色分级 danger红/warning黄/info蓝/success绿/primary）

**核心规则：只留比身上更好的（分部位对比）** ⭐
```
对比基准 = 当前穿戴的同部位装备评分
评分 = 词条数 × 红词条加权 + 高价值词条 + 等级权重

判断逻辑：
  ① 橙装（词条总值 516-585%）→ **无脑收** ⭐
     ⚠️ 原因：当前角色用不上，其他 11 个角色可能适用（装备角色间通用）
     → 橙装不看同部位对比，直接收进仓库备用
  ② 同部位已有装备（非橙装）：
     沙滩装备评分 > 身上装备评分 → 收（拾取后可替换穿戴）
     沙滩装备评分 ≤ 身上装备评分 → 清
  ③ 空部位（没穿装备）：
     直接收（新手期先凑齐全身装备最重要）
  ④ 段位初期修正：
     装备等级 ≥ 当前争夺等级上限（如 100 级上限出 100 级装）
     → 按词条价值收（这就是当前毕业装），不按"等级<200清理"一刀切
     明显低于上限（如 100 上限出 60 级）→ 清
```

**收取判断表（按优先级）：**

| 优先级 | 场景 | 收取 | 清理 |
|--------|------|------|------|
| 🥇 | **橙装**（词条总值 ≥516%） | ✅ **无脑收**（备其他角色） | - |
| 🥈 | 含神秘词条 / 星级≥2 | ✅ 必收 | - |
| 🥉 | 沙滩装评分 > 身上同部位 | ✅ 收 + 可选替换 | - |
| 4 | 空部位（未穿戴） | ✅ 收 | - |
| 5 | 沙滩装评分 ≤ 身上同部位 | - | 清 |
| 6 | 明显低于当前等级上限 | - | 清 |

> ⚠️ **橙装判定**：词条总值 = 各词条百分比之和，516-585% 为橙装（知识点确认）。沙滩装备 `data-content` 里每个词条带百分比，直接求和判断。
> ⚠️ **熔炼线**：词条总值 ≥410% **且品质 ≥稀有** 可熔炼为护身符（2026-08-06 实测 406%不可熔/425%可熔；2026-08-10 实测 418% 普通品质不可熔，返回"至少需要稀有级别的装备才可以熔炼"）；护身符在"我的饰品"栏即生效，不占装备槽。

**词条价值判断（针对角色构筑）：**
- **高价值词条**：生命偷取/附加物伤/附加魔伤/附加物穿/附加魔穿/技能概率/暴击概率/攻击速度
- **次要词条**：物理攻击%/魔法攻击%/生命值/护盾/暴击穿透/双抗
- **词条颜色**：红(danger)>黄(warning)>蓝(info)/绿(success)；红词条多 = 高品质

**饰品/护身符（实测确认，与装备同规则收取）：**
- 饰品位 = 8 槽（ca=1），与常规装备（ca=2）分开
- **护身符**（如"星铜苹果护身符 智力+2"）放入"我的饰品"栏**即生效**（Max 80）
- 饰品来源：**熔炼装备**（`c=9&id=&yz=`，yz=弹窗 readonly 值）/ 沙滩刷新 / 许愿池 / 翻牌
- **收取规则与装备完全一致**（分部位对比 + 橙装无脑收 + 必收条件）：
  - 橙装饰品（词条总值 ≥516%）→ 无脑收
  - 含神秘词条 / 星级≥2 → 必收
  - 评分 > 身上同槽位饰品 → 收
  - 空槽位 → 收
  - 评分 ≤ 身上同槽位 → 清
- 饰品评分 = 属性价值（护身符单属性 +N，Max 80 越高越好）+ 词条价值（葡萄/樱桃等百分比护符）

**配置项（脚本里做成可调）：**
```yaml
沙滩收取:
  启用分部位对比: true     # 只留比身上更好的（装备 + 饰品同规则）
  橙装无脑收: true         # 词条总值≥516% 直接收（备其他角色）
  高价值词条: [生命偷取, 附加物伤, 附加魔伤, 附加物穿, 附加魔穿, 技能概率, 暴击概率, 攻击速度]
  保留词条数: 3          # 词条数 ≥3 且含关键词条才收
  星级阈值: 2            # 星级 ≥2 必收（神秘/高品质）
  空部位必收: true        # 没穿装备/没装饰品的槽位直接收
  饰品同规则: true         # 护身符/饰品套用同一套收取判断
  自动清理: true          # 收完后 c=20 清理剩余垃圾
  强制刷新: false         # 是否 c=12 刷沙滩（耗装备箱）
```

**操作顺序（关键！）：**
1. 读取 `f=1` 沙滩列表，逐件解析（等级/星级/词条/颜色）
2. 逐件按规则判断：收 or 清
3. **先** `c=1&id=` 逐个拾取要收的
4. **再** `c=20` 一键清理剩余垃圾（⚠️ c=20 是整滩清理，非单件）
5. 清理收益：装备 → 锻造石（实测 15 件 → 35 蓝锻造石）
6. 可选 `c=12` 强制刷新再筛一轮

**实测要点：**
- 拾取返回 `"已放入仓库"`；穿戴 `c=3` 返回 `"已装备！"`
- 仓库装备查询 `f=2`（与沙滩 `f=1` 同格式）
- 新手期空部位多 → 先收不同部位（武器/袍/耳环/戒指），同部位只留最好

### 4.5b 仓库满处理规则（2026-08-10 新增）⭐

> 背景：仓库容量 = **35 格**（实测 18 件 + 剩余 17 空格）。沙滩/翻牌/许愿/工坊都会产出装备，**仓库满后无法继续拾取**（需先腾空间）。

**品质数字（装备唯一标识，取自 icon 文件名 `z2109_5.gif` 末位 `N`）：**

| 品质数字 | 含义 | 实测样本 |
|---------|------|---------|
| 1 | 低质 | 荆棘重甲304% / 陨铁重剑318% |
| 2 | 普通 | 大部分装备（404%探险者之剑等） |
| 3 | **稀有**（熔炼门槛） | 灵光袍430%（可熔） |
| 5 | 高质 | 陨铁重剑486%（神秘装） |
| 4/6 | 待确认 | - |

**仓库满触发条件：** `f=2` 返回"剩余 N 仓库空格"，N ≤ 阈值（默认 5）时触发整理。

**仓库整理优先级（从先到后）：**

```
① 检查沙滩 → 有装备先按 4.5 规则处理（该清的清，别让垃圾占用决策空间）
② 仓库内整理（见下方决策树）
③ 若仍满 → 丢弃低价值装备到沙滩（c=7，可逆！24h 内可捡回）
   → 再 c=20 清理沙滩回收锻造石（c=7+c=20 组合 = 无损清仓库）
```

**装备处置决策树（精细化版）⭐：**

```
对仓库每件装备（含沙滩新拾取的）：
├─ 橙装（总值 ≥516%）→ 留仓库 ⭐（其他角色可用，永不处理）
├─ 含神秘属性 → 留仓库 ⭐（神秘价值 >> 装备本身，永不熔炼/清理）
├─ 身上同部位评分 < 该装备 → 穿上替换（c=3），旧件回仓库继续评估
├─ 品质数字 ≥3 且总值 ≥410% → 熔炼为护身符（c=9&yz=124）⭐
│     ⚠️ 熔炼结果固定 = "星铜苹果护身符 随机属性+N"（与装备品质/总值无关）
│     ⚠️ 熔炼后装备消失 → 只有无神秘、非橙装、且无法替换身上时才熔
└─ 其余（总值 <410% 或 品质 <3 或 已被替换）→ 分批丢弃（c=7 丢沙滩）→ c=20 回收
```

**仓库整理触发条件与配置：**

```yaml
仓库管理:
  容量上限: 35           # 实测确认
  整理阈值: 5            # 剩余空格 ≤5 触发整理
  橙装保留: true          # 总值≥516% 永远留（备其他角色）
  神秘保留: true          # 含神秘永远留
  熔炼线: {总值: 410, 品质: 3}   # 双条件，2026-08-10 实测确认
  熔炼优先: true          # 可熔炼的先熔（护身符不占仓库格）
  丢弃方式: 丢沙滩再清理    # c=7 → c=20（可逆，安全）
  单批清理上限: 10         # 一次 c=20 上限（超了分批）
```

**操作顺序（仓库满时）：**
1. `f=2` 读仓库 → 解析每件（品质数字/总值/神秘/部位）
2. 先处理沙滩（4.5 规则）→ 腾出临时空间
3. 按决策树遍历仓库：替换穿戴 → 熔炼 → 标记丢弃
4. `c=3` 替换装备；`c=9` 熔炼达标件
5. 剩余丢弃件 `c=7` 逐件丢沙滩（⚠️ c=7 单件可逆）
6. `c=20` 清理沙滩回收锻造石
7. 复查 `f=2` 空格数 → 满足则结束，否则循环

> ⚠️ **熔炼 vs 回收 vs 留仓 三选一判断口诀：**
> - **神秘装/橙装** → 留仓（价值最高）
> - **品质≥3 且总值≥410% 且无神秘** → 熔炼（变护身符不占格）
> - **其余** → 回收（换锻造石）
> - **绝不**把神秘/橙装拿去熔炼或回收（巨亏，2026-08-10 实测教训：486% 神秘陨铁重剑熔成 +2 护身符）

## 4A. 每日日常自动化流程（完整可执行）⭐核心

> 综合接口文档（实测）+ 玩家日常（知识点）+ slack 源码流程设计。**按此顺序执行即可完成一天全部收益**。

### 执行时序（建议：每天固定时刻跑一次，如早上 8 点前）

```
[0] 认证准备
    → GET fyg_index.php 确认登录（含用户名）
    → 提取 safeid（正则 &safeid=([^"]+)"）
    → 读取战场状态 f=12 获取：段位/进度/今日狗牌/出击次数

[1] 宝石工坊收菜（每日收益，最重要）
    → 读取 f=21（工坊状态：已开采星沙数）
    → 若可收工：POST fyg_click.php c=30（收工统计收益）
    → 立即开工（收完工即开工，重复循环）
    → 判断"已开采星沙"是否达阈值（如 ≥10），达标才收

[2] 商店日限（B 段开放）
    → POST fyg_shop_click.php：
        c=11 领 BVIP 打卡包
        c=12 领 SVIP 打卡包
        c=5  星沙→贝壳（1:10w，可配置开关）
        c=6  星晶→贝壳（1:120w，氪金慎开）
        c=7  买体能药水（连买到目标数）
    ⚠️ 需先 GET fyg_shop.php 确认开放（B 段以上）

[3] 许愿池
    → 读取 f=19（许愿内容/贝壳余额）
    → 若开启许愿：POST fyg_click.php c=18&id=<次数>
      （1次=30w 贝壳 / 2次=60w / 3次=90w；余额不足自动降次）

[4] 沙滩（装备收取 + 清理）
    → 读取 f=1（沙滩装备列表：等级/星级/词条）
    → 按 4.5 规则筛选：
        逐件判断 必收/择优收/垃圾
        必收+择优收 → c=1&id=<装备id>（逐个拾取）
    → 剩余垃圾 → c=20 一键清理（回收锻造石）
    → 可选 c=12 强制刷新（耗随机装备箱）再筛一轮
    → 更新仓库 f=2（确认空格充足）
    → **若空格不足（≤5）→ 按 4.5b 仓库满处理规则整理**

[5] 争夺战场 · 出击（核心，拿狗牌 + 升段 + 经验）
    → 读取 f=12 确认状态
    → 循环出击（目标 3 狗牌即停；可配置打满 20 次）：
        POST fyg_v_intel.php id=1（打野）或 id=2（打人）
        解析战报判定胜负（2026-08-06 实测确认）：
          "＜我方用户名＞ 获得了胜利！" → 胜
          "＜对手/野怪名＞ 获得了胜利！" → 败（与胜利同格式，必须解析主语！）
          "双方同归于尽" → 平局不计次数
          其他 → 失败兜底
        处理特殊返回：
          "请重试" / "随机对手近日无胜场" → 不计次数，立即重打
          "轮空或对手段位改变" → 重打
        每 5 次读 f=12 刷新狗牌计数
    → 停止条件：**今日狗牌 ≥3 即停**（2026-08-10 实测确认：翻牌只需 3 狗牌入场，打满 10 狗牌无额外奖励；剩余次数留作冲段/打装备。可配置 `打满20次` 开关）

[6] 翻牌（抽卡，每日核心奖励）
    → 确认狗牌 ≥3（f=12；**狗牌=入场资格，翻牌不消耗狗牌**，2026-08-10 确认）
    → 读取 f=10（翻牌区 + 透视）
    → 若含透视 `是"幸运/稀有/史诗/传说"` → 按透视精准翻 3 同色
    → 若无透视 → 策略翻牌（参考 slack）：
        循环 c=8&id=1..12 翻牌（每张每天 1 次，最多 12 次/天）
        每翻一张刷新 f=10 看结果（按钮文本=品质）
        出现某色 ≥2 → 追该色保底
        出现传说 ≥2 → 无脑翻
        否则从左到右翻
    → 同色 3 张 → 结算获得对应品质奖励（**每日仅结算 1 次**，结算后剩余牌作废）→ 每日翻牌完成

[7] 额外奖励（可选，消耗药水）
    → c=13&id=1：消耗 1 药水，再领一次翻牌奖励
    → c=13&id=2：消耗 2 药水，重置今日狗牌+翻牌（重新打狗牌再翻）

[8] 收尾
    → 密钥续期：POST fyg_llpw_c.php iu=2（若用密钥登录）
    → 记录日志（出击数/狗牌/翻牌结果/工坊收益）
```

### 各步骤依赖与容错

| 步骤 | 前置条件 | 失败处理 |
|------|---------|---------|
| 工坊收菜 | 登录 | 失败重试 2 次；跳过继续 |
| 商店 | B 段开放（`fyg_shop.php` 非 shop_err） | 未开放跳过 |
| 许愿 | 贝壳 ≥30w | 不足降 1 次或跳过 |
| 沙滩 | 有装备 | 空沙滩跳过清理 |
| 出击 | 体力 >0 | 体力 0 用 `c=13&id=2` 重置（耗药水） |
| 翻牌 | 狗牌 ≥3 | 不足 → 先去出击；出击失败 → 跳过今日翻牌 |
| 密钥续期 | 用密钥登录 | 失败不影响游戏 |

### 收益优先级（资源紧张时）
1. **工坊收菜**（纯白嫖收益，必做）
2. **出击 ×3 狗牌**（翻牌前提）
3. **翻牌**（每日核心奖励，涨神秘系数/经验）
4. **商店打卡包**（BVIP/SVIP 白嫖）
5. **许愿**（贝壳充裕才做，长期投资）
6. **沙滩清理**（有装备才做，装备箱有溢出再刷）

### 定时策略
- **推荐早上 8 点前执行**（多帖印证出击胜率高、进度好冲）
- 药水/狗牌重置（c=13&id=2）建议留到出击前用，最大化当日出击次数
- 密钥续期固定凌晨 1 点（slack 做法）
