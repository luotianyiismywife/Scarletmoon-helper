# 旧争夺油猴脚本（feiyue2）

> 纯自用旧争夺自动化脚本（**feiyue2**，v0.2），记录于 2026-08-13。
> 无第三方 js、无混淆加密，仅原生油猴函数 + 原生 JS；不记录任何信息；`GM_setValue` 数据仅存本地，且只用于劫持页面函数。

## 功能概述

1. **自动开启争夺**：打开 `kf_fw_ig_index.php`（争夺主页）后自动点"战斗（前进至结束）"（`jgjg('99')`），随后打开签到页 `kf_growup.php`
2. **签到自动领奖励**：在 `kf_growup.php` 自动点每日奖励链接（`gro_divhui` 区域），已领过则跳过
3. **劫持 `rlzb_qr`**：保存原始函数后用自定义 `myfun` 替换（`GM_setValue("originalFunction", rlzb_qr)` 备份），自定义版通过 AJAX `kf_fw_ig_mybpdt.php?do=5&id=<zbid>&safeid=<sid>` 局部刷新背包项
4. **自动开箱/卖装备**（`kf_fw_ig_mybp.php` 背包页）：
   - 有传奇箱子（`num>0`）→ 逐个开（`dkhz('4')`，2s 间隔）
   - 无箱子时（`num="0"`）：
     - 物品列表长（`thing.length > 3`）→ 遍历 2~22 行售出物品，**跳过黑名单**：`消逝之药 / 整形优惠卷 / 十六夜同人漫画 / 蕾米莉亚同人漫画 / 档案室钥匙 / 傲娇LOLI娇蛮音CD`；到 22 行刷新页面
     - 物品列表短 → 遍历 2~12 行，**默认保留"神秘"和"1极"属性**，其余卖出；到 12 行刷新
5. **每月 3 号弹窗**提醒还信用卡：`alert("pay credit card loan")`（注释掉即取消）

## 使用说明

1. 复制脚本到油猴 → 新建脚本 → 保存
2. 打开 `https://bbs.kfpromax.com/kf_fw_ig_index.php` → 自动开启争夺并打开签到页面
3. 点击物品自动开传奇箱子；开完刷新自动售卖物品
   - 默认保留神秘属性，可自行修改此行：
     ```js
     if(ms[i1].indexOf("神秘") >= 0 || ms[i1].indexOf("1极") >= 0) {
     ```
4. **域名适配**：在 `var index = [...]` 里添加域名，并在脚本头添加对应 `// @match`
5. 3 号弹窗还信用卡提醒：注释 `alert("pay credit card loan")` 即可；或浏览器屏蔽该网页弹窗

## 涉及页面（旧争夺接口）

| 页面 | 用途 |
|------|------|
| `kf_fw_ig_index.php` | 争夺主页（判断"战斗（前进至结束）"按钮） |
| `kf_fw_ig_mycard.php` | 卡片页（匹配用） |
| `kf_fw_ig_mybp.php` | 背包/装备页（开箱、售卖） |
| `kf_fw_ig_mybpdt.php` | 背包项详情（`do=5&id=<zbid>&safeid=<sid>` 局部刷新） |
| `kf_growup.php` | 论坛签到（每日奖励领取） |

> 注：`jgjg('99')`、`rlzb_qr`、`dkhz('4')` 均为页面自带的全局函数（脚本劫持/调用）；脚本逻辑依赖页面 DOM 结构（`.ind01`、`.gro_divhui`、`.kf_fw_ig1`、`.kf_fw_ig4` 等），论坛改版后需同步调整。
