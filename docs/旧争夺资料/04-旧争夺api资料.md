## 1. 基础信息

| 项目 | 值 |
|------|-----|
| 域名 | `bbs.kfpromax.com`（旧争夺也在论坛内，非独立域名） |
| 编码 | **GBK**（同论坛） |
| 入口 | `kf_fw_ig_index.php`（争夺主页；论坛首页"争夺奖励"直链，新注册号可能看不到入口但直链可进） |
| 认证 | 论坛 cookie（`2ed4e_*`）+ 页面内 `safeid` 防伪令牌 |

## 2. 页面接口

| 页面 | 用途 | 关键动作 |
|------|------|---------|
| `kf_fw_ig_index.php` | 争夺主页 | 自动点「战斗（前进至结束）」= `jgjg('99')`；随后跳签到页 |
| `kf_fw_ig_mycard.php` | 卡片页 | 匹配用 |
| `kf_fw_ig_mybp.php` | 背包/装备页 | 开箱 `dkhz('4')`；物品行遍历售出 |
| `kf_fw_ig_mybpdt.php` | 背包项详情 | `do=5&id=<zbid>&safeid=<sid>` 局部刷新背包项（AJAX） |
| `kf_growup.php` | 论坛签到 | 每日奖励领取（gro_divhui 区域；已领过跳过） |

> ⚠️ **函数依赖页面 DOM**：`jgjg('99')`、`rlzb_qr`、`dkhz('4')` 均为**页面自带的全局 JS 函数**（脚本劫持/调用），DOM 结构（`.ind01`、`.gro_divhui`、`.kf_fw_ig1`、`.kf_fw_ig4` 等）改动后脚本需同步调整。

## 3. 已知接口细节

### 3.1 战斗（前进至结束）
- 触发：`jgjg('99')`（页面全局函数，99 = 打到结束）
- 打开主页后自动点一次，随后打开签到页

### 3.2 背包项局部刷新
- `GET/POST kf_fw_ig_mybpdt.php?do=5&id=<zbid>&safeid=<sid>` → 刷新单个背包项（原 `rlzb_qr` 行为，被脚本劫持为自定义 `myfun`）

### 3.3 开箱 / 售卖
- **开传奇箱子**：`dkhz('4')`（页面函数），有传奇箱（`num>0`）时逐个开，间隔 2s
- **售出物品**：遍历背包行（2~22 或 2~12 行，视列表长度），跳过黑名单：
  `消逝之药 / 整形优惠卷 / 十六夜同人漫画 / 蕾米莉亚同人漫画 / 档案室钥匙 / 傲娇LOLI娇蛮音CD`
- 列表短时默认保留「神秘」「1极」属性，其余卖出

### 3.4 签到
- 论坛签到页 `kf_growup.php`，自动点每日奖励链接（`gro_divhui` 区域）
- 已领过判定/领取接口同论坛签到（见 网站api资料.md §3.1）
