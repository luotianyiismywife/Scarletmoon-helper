## 与咕咕镇（新争夺）资料的关系

- 两套系统**独立但互斥**：玩一边会 ban 另一边收益 7 天（详见 01）
- 咕咕镇资料里凡是提到"旧争夺"的内容，其**完整版**都在本资料库；咕咕镇侧只保留交叉引用摘要
- **单一事实来源**：旧争夺专属知识只写在这里；两系统共有内容（如论坛 API、装备词条体系）仍在各自资料库，文档间互引不重复

## 维护约定

- **新知识** → 写入 `01-旧争夺知识点.md` 对应主题分区；**新脚本/接口** → `02-脚本.md`
- **帖子抓取/重排**：`python tools/fetch_posts.py --dir 旧争夺资料 --index 03-论坛帖子索引.md`（抓未读，`--images` 可附图）→ `fetch_publish_time.py` + `sort_posts.py`（同参数，补时间/重排表格）
- **定期重扫帖子**：搜索"旧争夺"（GBK 编码），方法同咕咕镇侧（见 [咕咕镇-新争夺资料/06 索引](../咕咕镇-新争夺资料/06-论坛帖子索引.md)「重新扫描方法」节）；每次扫描后在 `03` 的「扫描历史」表追加记录
- **引用规范**：文档间一律用本目录相对路径（如 `[01-旧争夺知识点.md](01-旧争夺知识点.md)`）
- **单一事实来源**：接口细节只写 `02`/网站api资料，知识点只写 `01`，其余文档引用而非重复
- 知识点现状：`01` 已由 358 篇帖子精读完成初版（2026-08-13）；后续新帖干货按主题补入 `01` 对应分区
