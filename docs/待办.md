### ✅ 出击逻辑闭环已确认（2026-09-05，打野失败不切回打人修正版）
```
打人:
  ├─ 赢 → 狗牌+1,进度+3%
  ├─ 轮空/平局 → 切打野
  └─ 输 → 连败+1,切打野
打野:
  ├─ 赢 → 狗牌+1 ✅ 目标达成
  ├─ 平局 → 🔄 换角色重来（从打人开始）
  └─ 输 → 连败+1,留在打野继续（不切回打人）
连败 5 次 → 进度-20 → 进度清零掉段 → 送 1 狗牌 + 野怪等级大幅下降 → 更好打
```
**结论：逻辑闭环无问题**——打野失败**不切回打人**（修正 2026-09-05）：
切到打野的前提是打人不可用（匹不到轮空/打不过），切回去只会 pvp/pve 来回
空转 = 死循环；留在打野稳定累计连败 → 掉段送狗牌 + 野怪变弱 → 自然破局。
打野平局 → 换角色；打人轮空 → 切打野。无需额外"主动送败"策略
（连败/掉段是自然过程）。
