## 4. 游戏规则（抓包确认 + 帖子知识点）

### 4.1 争夺战场（fyg_pk.php）
- **攻击玩家**：胜利 狗牌+1、进度+3%；失败 进度-3%
- **攻击野怪**：胜利 狗牌+1、进度+1%；失败 进度-1%
- 每日需 **3 枚狗牌** 才能翻牌（2025-01 后）；胜利都得 1 狗牌
- 页面数据：段位/进度%/今日狗牌/今日出击次数/连胜/连败
- **100 回合平局不计次数**（无收益）
- PVP 特殊消息："随机对手近日无胜场，不计出击次数，请重试" / "随机匹配轮空或对手段位改变...本次不消耗体力"
- **防守全败不掉进度**（可只打进攻）
- **战斗记录** `f=25`：只显示 **24 小时内**出击/被攻击记录（PKP 才有记录）
- **野怪天赋（fyg_pk.php 页面说明，2026-08-10 抓取）⭐**：
  ```
  反伤减伤 50%、物理/魔法伤害减伤 90%、绝对伤害减伤 88%
  （= 源码 AURA_DI 绝对底线：物/法伤×0.1、绝伤×0.12）
  ```
  → **打野必须靠绝对伤害/削骨之痛等天赋**，纯物理/魔法输出被减 90%
- **胜率表** `fyg_stat.php`：全站战绩统计（10月1日清空），纵列红卡对横行蓝卡胜率（进攻/防守分列），>90%深绿 />70%浅绿 / <30%浅红；空=战斗次数过少

**掉段机制（2026-08-06 实测确认）⭐：**
- 段位进度降至 **0%** → 触发降级（CCC→CC），并：
  - **自动送 1 枚狗牌**
  - 段位进度重置为 **90%**
  - 连胜/连败计数清零
- 掉段后野怪等级大幅下降（实测：CCC 段野怪 Lv.38 → CC 段 Lv.10），可轻松取胜回段
- 与"升段 +10% 进度、掉段 →90%"和"A 段以下掉段自动给 1 狗牌"两条帖子规则吻合

**升段机制（2026-08-06 实测确认）⭐：**
- **5 连胜直接升段**（无需等进度 100%）：CC 连胜 5 场 → CCC，进度重置 **10%**（升段 +10%），连胜/连败清零，狗牌保留
- 升段后**野怪等级暴涨**（实测：Lv.11 → Lv.36），若装备不足会立刻连败掉回原段

**⚠️ 低段位瓶颈（2026-08-06 打满 20 出击实测）⭐：**
- **CCC 段是当前装备瓶颈**：野怪 Lv.36《绝对底线》反伤（物/法减伤 90%），需**绝伤属性**才能打；打不过 → -1%/场
- **PVP 在低段位轮空**：连续 4 次"随机对手近日无胜场，不计出击次数"→ 升段只能靠 5 连胜打野
- **CC ↔ CCC 横跳死循环**：CC 野怪 Lv.11 稳赢 5 连胜升 CCC → CCC 野怪 Lv.36 必败掉回 CC → 循环
- 升到 B 段（商店开放）需要：提升装备（堆绝伤）突破 CCC 段，或等 PVP 匹配到人
- 打满 20 次出击：今日共得 **12 狗牌**（20 出击 = 12 胜 8 败，胜率 60%）
- **上限消息复测**：第 21 次出击返回 `今日已主动出击20次，达到上限，请明日再出击`（31 字节）

### 4.2 翻牌（主页 fyg_index.php）
- **12 张牌** = 4 色（幸运/稀有/史诗/传说），**每色恰好 3 张**（3+3+3+3），品质**预分配且隐藏**，位置随机打乱
- 翻牌动作：`giftop(id)` → `c=8&id=<1-12>`（id 从 1 递增，从左到右）
- **翻牌透视（slack 源码验证）**：`f=10` 返回含 `是"(幸运|稀有|史诗|传说)"` 文本（若开启透视）→ 可按透视决定翻哪张
- **翻牌结果解析**：f=10 返回的按钮文本（`//button[contains(@class,'fyg_lh60')]`）累计各色张数
- **⭐ 已翻牌判定（2026-08-11 实测）**：已翻开的牌 = `btn-info/success/warning/danger` 带色按钮（未翻 = 无 btn-* 色），**颜色→品质映射**：
  | 按钮 class | 品质 |
  |-----------|------|
  | `btn-info` | 幸运 |
  | `btn-success` | 稀有 |
  | `btn-warning` | 史诗 |
  | `btn-danger` | 传说 |
- **翻牌策略**：某色 >1 张时追求保底（2幸运→保底翻完）；2传说→无脑翻
- "获取额外奖励" = `c=13&id=1`（消耗 1 药水再领奖励）；`c=13&id=2` = 消耗 2 药水**重置今日狗牌和翻牌**（同时刷新出击数）

**⭐ 翻牌核心机制（2026-08-10 完整实测确认）：**
- **狗牌 = 入场资格**（每日 ≥3 枚才能翻牌），**不消耗、不按次数**（有几个狗牌 ≠ 翻几次）
- **每张牌每天可翻 1 次**，最多翻 12 次/天（每张一次），与狗牌数无关
- **凑 3 同色 → 结算**：翻出任意 3 张同色立即结算，**每日只结算 1 次**；结算后剩余牌作废
- 翻牌不消耗出击次数、不消耗狗牌、不消耗体力

**翻牌结算实测：**
- **单张翻牌**：`c=8&id=N` 返回**空字符串**（len=0）= 成功，牌面翻开显示品质- **已翻牌再点**：返回 `该牌面已翻开`（2026-08-12 实测）

  → 结算由 c=8 返回体直接携带（含"获得"字样），脚本判 `"获得" in 返回` 即可- **结算奖励弹窗**（2026-08-06，3 同色）：约 399 字节：

- **结算触发**（2026-08-10）：翻卡1-4 各出 1 色（稀有/幸运/史诗/传说），继续翻到卡7/8 再出 2 传说 → **3 传说触发结算**，+2895 贝壳（主页贝壳 199138→202033）。翻出 8 张共：稀有×1、幸运×2、史诗×2、传说×3

  - `收益 = 颜色基础值 × (1 + 段位进度 × 0.3)`，100% 进度 = **1.3 倍**上限（**公式为帖说**，实测仅 3 数据点，8929≈7000×1.276 单点吻合）

### 4.3b 工坊数学期望与最优收工（2026-08-11 分析）⭐⭐

**机制确认（实测线性）：** 概率栏 = 增长率 × 分钟数（线性），**100% 封顶**；贝壳/星沙/幻影 = 直接累积
**⚠️ 概率栏 100% 封顶 = 收工时该栏产出 1 件**（单件判定事件，不会突破到 200-300% 产出 2-3 件；开工时间再长每栏最多 1 件）

**当前增长率与封顶时间：**
| 栏 | 类型 | 增长率 | 角色 | 100%/上限封顶 | 单位时间价值(估) |
|---|---|---|---|---|---|
| 贝壳 | 累积 | +40/分 | 默190 | 无上限 | 40/分 |
| 星沙 | 累积 | +0.0019/分 | 霞800 | **10粒 = 87.7h** | **190/分**（商店10w/粒） |
| 装备箱 | 概率 | +0.022%/分 | 薇193 | 75.7h | 110-220/分 |
| 原石 | 概率 | +0.033%/分 | 命800 | **50.5h** | 99-165/分 |
| 幻影 | 累积 | +0.056/分 | 梦800 | 无上限 | 56-112/分 |
| 灵魂药水 | 概率 | +0.0165%/分 | 琳186 | 101h | **0（废弃）** |

**数学期望核心结论：**
```
概率栏 P(t) = r×t（线性，100% 封顶）
收工间隔 T 的期望 E(T) = r×T
单位时间期望 E(T)/T = r → 恒定！（封顶前）
```

**⭐ 结论：等 100% 再收是误区**
1. **收工时间 ≤50.5h（最早封顶=原石）任意时刻，单位时间收益相同** → 每天收一次（24h）不亏
2. **超过 50.5h 必亏**：原石停止增长，边际收益骤降
3. **"等 100% 保底拿"**只在心理上有意义（确定性 vs 概率），期望值相同
4. **药水栏纯浪费**（灵魂药水废弃，价值 0）

**真正提升收益的手段（优先级）：**
| 手段 | 效果 | 说明 |
|------|------|------|
| 加宝石（c=27） | 提高对应栏增长率 | 实测红石 1→2：贝壳 +14% |
| 梦石 → 原石复利 | 更多原石 → 更多升级 | ⭐ 知识帖首选 |
| 收集 12 角色卡升级 | 加工角色等级↑ → 增长率↑ | 无卡=0级严重拖累 |
| 提升虚石 | 星沙↑（最高价值栏） | 商店 10w/粒 |

**宝石升级成功率**：`基础概率 × (上限-当前)/上限` → 前期好升后期难（红石 1→50 递减）

**推荐日常：每天收 1 次（24h）**，别等 100%；最长 50.5h 必须收

### 4.7 战斗公式（guguzhen-calculator 源码对照，2026-08-06）⭐
来源：`newkf.cpp` 的 `calcBattle()`：
- **100 回合平局**：`if (round == 100) break;` → `br.winner = 2`（平局，与游戏内"100 回合不计次数"吻合）
- **胜负判定**：`wf` 位标记死亡方，`br.winner = wf-1`（0=攻胜 1=守胜 2=平）；`rate = 存活方(hp+sld)/(hpM+sldM)`
- **AURA_DI（绝对底线）**：物/法伤 ×0.1、绝伤 ×0.12 → 减伤 90%/88%，**与实测野怪天赋文案完全吻合**
- **等级压制**：`levelPower = 攻防等级差`（上限 20），伤害 ×(1+0.03×levelPower) → 最多 +60%
- 护盾机制：先扣护盾（sldActive），破盾后伤害溢出转生命；减伤 `calcDefRate()` 按防御/穿透计算
- 各角色技能（舞/梦/默/冥/希等）与光环（圣盾/走位/穿透/吸血等）均有对应代码，可作战斗模拟器参考
