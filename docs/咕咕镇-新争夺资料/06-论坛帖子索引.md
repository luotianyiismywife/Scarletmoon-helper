## 重新扫描方法（2026-08-12 用户教）⭐

> 目的：定期重扫论坛，找出**新帖**和**旧帖的新回复**，无需逐篇点开。

**核心原理：搜索页的"发表"列显示的是「最后回复时间」，不是发帖时间。**
→ 用**最后回复时间**对比「上次扫描时间」即可判断有没有新内容：

| 判断 | 方法 |
|------|------|
| **新帖** | tid 不在索引表格里 → 直接收录（其最后回复时间自然 ≥ 上次扫描时间） |
| **旧帖有新回复** | tid 已在索引，但搜索页的最后回复时间 > 上次扫描时间 → 需翻帖看新回复 |
| **无新内容** | 最后回复时间 ≤ 上次扫描时间 → 跳过 |

**上次扫描时间**：见下方「扫描历史」表最近一次记录。

**操作步骤：**
1. 全站搜索"咕咕镇"（`search.php`，GBK 编码 keyword，每页 60 条）
2. 从搜索结果提取每行：`tid` + 最后回复时间（末列）
3. 与索引表格比对：新 tid → 记录；旧 tid 且回复时间 > 上次扫描 → 标记待看
4. 逐篇打开待看帖，只读**上次扫描之后的楼层**（翻页定位），提取干货 → 补入 01 知识点；水帖 → 不更新
5. 新帖按状态追加到表格头部（✅已读 / ⏭️跳过），更新篇数
6. **在下方「扫描历史」表追加本次扫描记录**（日期 + 结果摘要）

> ⚠️ 注意：旧帖新回复可能分布在**第 2 页起**（如 tid=1083074 的 08-07 回复在第 2 页），需翻页定位；`fetch_posts.py` 抓取的是全帖，新回复需人工甄别价值。
