## 3. 各角色详细配置

### 舞（zid 3000）—— 主练
- **加点**：主力量敏捷，靠装备撑血量和技能率，点少量精神叠护盾
- **技能**：闪避突袭/鲜血渴望赖着不死耗死对面；反伤流是克星
- **配装路线**（2025-09-15 环境）：
  - 攻速流：攻速刃（神秘）+ 折光戒指 + 反伤甲（神秘）+ 猎魔耳环；天赋三倍攻速 + 花盆
  - 护盾流多时：刺杀弓（神秘）+ 天赋"自信回头"替代三倍攻速
  - 全敏流：彩金长剑打真伤，1800 敏/10w 血/11500 攻速 + 飓风之力 + 对剑真伤 + 花盆，一刀暴击 16w 真伤
- **打野配装**：神秘重剑 + 沸血，剩下堆吸血和 HP 上限
- **打野作业（2026-05-22 tid=1079827）⭐**：刃 + 海戒 + 斗篷 + 猎魔，**三刀流秒杀**（堆暴击+技能概率，3 刀秒怪，不靠磨）
- **满速构筑**：速度加满胜率翻倍但血量少（打人绝伤 17w 要求血量 ≥80w）
- **海星戒指 = 舞专属**（神秘增伤）
- 不推荐（当前版本）：刃舞/对剑舞有上位替代

### 梦（zid 3005）—— 打野 T0
- **加点**：主敏捷 + 精神（第三回合攻击次数 ≥3 次，不够加敏，够了全精）
- **装备四件套**：幽梦匕首 / 秃鹫手环 / 旅法师的灵光袍 / 占星师的耳饰
- **PVP**：先 100-200 智力，其余平均敏/精
- **弱（PVP）**：精神护盾效率太低（2832 精神护盾 400w+ → 现在约 240w）
- **匕首只看 34 词条**，伤害来源是**被动（出手次数）**；头饰只看 25 词条（上限 90% 最大护盾）
- 极低卡等推荐梦；打野登顶导致野怪等级暴涨（慎连胜刷野）

### 薇（zid 3006）—— 打野 T1
- **对剑薇**：智力至技能率 800+，体魄意志按环境穿透调，余全敏；装备 34 对剑/24 冥戒/14 反甲/134 神秘薇头；光环 SHI XIN XIAO RE JU PIAO
- **剑盾薇**：1-100 力 500+ 敏 2000+ 意志 少量体；装备 2 神秘剑盾/24 冥戒/14 反甲/14 神秘薇头
- **薇主动技能减免 90% 伤害**（先手后除反伤外无解）→ 薇多的时间段出击用薇克制
- 强势：对剑薇（与剑盾冥换着用普遍 3S 100%）；缺点太脆 SSS 段没人玩

### 冥（zid 3008）—— PVP 强势 / 打野下水道
- **被动双抗减半** → 物防魔防不重要，选高反伤/吸血；**剑盾就是为了反伤**（冥自带 40 反伤）

### 伊（zid 3007）—— 打野 T1

## 3b. 构筑通用原则与流派（并入自 01 §11）

### 构筑通用原则

- **优先级（高→低）**（2026-05-19 saeki 干货）：0. 别玩咕咕镇会变得不幸；1. 别玩法系；2. 别玩梦；3. 参考计算器调加点
- **法系弱于物理系**：除黑榜前列鲨鱼外，全系数均不如物理系；有锻造箱建议趁早转型
- **万金油思路**：任何角色都是"堆血 + 沸血"，简单省事（nu2005）
- **伤害公式示例**（saeki 补充）：神秘弓 0.18 × 2(暴击) × 1.25(物伤对护盾) × 1.4(pen) × 1.5(zi) × 0.9(zhi) × 1.55(命被动) = 不可描述（pen 数值怪版本）
- **当前版本核心是"穿透"攻防博弈**：高耐久流派面对飓风流只需适当穿透；刃/霞杖需足够穿透才能有效输出
- **神秘等级影响远大于装备影响**；同神秘等级间角色有优劣势关系
- 流派参考帖：tid=1042779「20241010 S-SSS 大段常规流派」（在列表内，待精读）；tid=1079827、tid=1080138（舞玩家参考，标题不含"咕咕镇"故不在搜索列表）
- 术语："N技M品" = N 个技能槽 + M 品质（如"4技8品的舞"）；光环配置常用拼音缩写（如 SHI XIN = 启程之誓+启程之心 系）

### 社区主流加点共识（2026-09-05 汇总，帖说待实测）

- **梭哈流**（无言的喧嚣，疑问帖 tid=1083618 8楼）：体/意各 1000、敏/智各 500；重甲无所谓、重剑最好带神秘、剩余堆吸血+HP、挂沸血
- **萌新流**（萌新配装节）：除敏捷和攻击其他不点；敏捷点到野怪三倍左右；扛不住点 20 精神
- **万金油**（nu2005）：任何角色"堆血 + 沸血"
- **共同点**：社区不做"主属性 60% 极限堆"（单项上限=总×60% 是硬上限，没人贴上限堆），而是**均衡盾血 + 速度**；且默认**一个号一套加点**，无按角色区分之说
- **与脚本对照**：ADDPOINT_STRATEGY（主属性 60% + 副属性轮流）是自创增强，与社区均衡思路不同；后续调参可参考梭哈流（体意盾 + 敏智速）方向

## 4. 切角色打怪注意事项 ⭐

1. **角色卡等级独立**：每个角色卡有自己等级/成长（如舞 Lv.801，其他卡默认 800 初始，需各自练），切卡后加点/装备要跟着切
2. **野怪绑定角色**：不同角色对应不同野菜（强度差异大）；**打不过当前野菜 → 换卡是有效思路**（新卡绮打野可偷渡：AAA 野怪仅 200 级）
3. **装备不共用**：各角色装备独立配置（舞的配装 ≠ 梦的配装）
4. **出战中标记**：f=8 `xxcard(zid)` + "(出战中)" 标记；切卡改出战角色后，出击/加点目标跟着变
5. **⚠️ 加点实测共享（2026-09-05 修正）**：六维加点**全角色共享**——给默提交"精神+1/力量-1"后，舞同步变化（f=18 验证，12 角色六维完全相同 1562/20/20/471/10/521）。旧记录"加点独立（f=18 zid=角色）"已废弃。**任何角色加点 = 全角色生效**，加点策略只需一套（主练角色优先）
