## 1. 装备基本结构

每件装备 = **1 个部位 + 4 条词条**（每词条 = 名称 + 数值 + 百分比）：

```
附加物伤 +2500  125%     ← 词条1（warning黄）
附加物伤 +2320  116%     ← 词条2（success绿）
物理攻击 +47.5%  95%     ← 词条3（info蓝）
暴击穿透 +9%    150%     ← 词条4（danger红）
[神秘属性]xxx             ← 可选第5项（神秘）
Lv.100 陨铁重剑          ← 等级 + 名称
```

- **百分比 = 词条质量**：决定数值大小（数值 = 装备等级 × 词条百分比，简单乘算）
- **等级上限 300**（争夺等级 <100 只出 100 级装备，装备等级跟随角色等级）
- **4 个词条槽固定**，无额外词条位

## 2. 词条颜色与品质体系

### 2.1 词条颜色分级（实测 HTML class）

| 颜色 | class | 等级 | 说明 |
|------|-------|------|------|
| 🔴 红 | `danger` | 最高 | 词条质量最高（仓库橙装常见） |
| 🟡 黄 | `warning` | 高 | 词条质量高 |
| 🟢 绿 | `success` | 中 | 词条质量中等 |
| 🔵 蓝 | `info` | 中低 | 词条质量中低 |
| ⚪ 白/灰 | `primary` | 低 | 词条质量最低（基础） |

- 装备按钮 `data-tip-class="popover-XXX"` 反映装备**整体品级**（danger红/success绿/info蓝/primary）——**由品质数字决定**（见 2.4：品质1→primary灰、2→info蓝、3→success绿、4→warning橙、5→danger红）
- 已实测样本：词条总值 584% 探险者之剑 = 品质4橙（4 红词条）；灵光袍 430% 有 1 红词条（142%）但品质3绿 → **tip 色 = 品质数字，与词条颜色无关**

### 2.2 橙装（词条总值定义）

> 帖子知识点（2026-05-06 装备数值机制）：**橙装 = 装备词条总值在 516%-585% 之间（仅此含义）**

- **词条总值 = 4 条词条百分比之和**
- 例：探险者之剑 150+139+145+150 = **584%** → 橙装
- **判断橙装直接看总值 ≥516%**，不看颜色
- ⚠️ 与"品质红黄蓝绿白"是两套概念：橙装特指总值 516-585%，品质红黄蓝绿白是词条色级

### 2.3 品质（词条颜色）与神秘

> 帖子知识点（2026-03-16 日常玩法帖）：**品质红黄蓝绿白，黄色开始出神秘给对应角色 buff**
> ⚠️ **2026-08-10 实测修正**："黄色出神秘"不准确——实际是**品质数字 ≥4（橙/红底色）才可能出神秘**（品质2 海星戒指/灵光袍含黄词条但无神秘）

- 词条颜色分级（2.1）：primary白 < info蓝 < success绿 < warning黄 < danger红
- **神秘出现条件 = 品质数字 ≥4**（2026-08-10 实测：品质4 复苏战衣=神秘、品质5 陨铁重剑=神秘、品质4 探险者之剑584%=**无**神秘 → **概率触发非必然**）
- **SSS 段锻造品质保底橙**（2024-07-21 锻造规则）
- **5% 概率出神秘红**（无神秘装备则加基础品质）；连续 11 次无红，第 12 次保底必出神秘红
- 神秘红 = 带神秘属性的红装，顶级

### 2.4 品质数字（icon 文件名末位，2026-08-10 实测）⭐

> **装备品质等级 = 数字**，两处可见（互证）：仓库/沙滩按钮的 icon 文件名 `z2109_5.gif` 末位；身上装备按钮的 class `fyg_colpzXXbg`（XX 即品质数字）

| 品质数字 | 颜色 | 图标底色 RGB（实测） | 按钮 class | tip色 | 实测样本 |
|---------|------|---------------------|-----------|--------|---------|
| 1 | ⚪ 灰 | (163,159,162) | `fyg_colpzbg` | primary | 荆棘重甲304% / 陨铁重剑318% |
| 2 | 🔵 蓝 | (127,189,200) | `fyg_colpz02bg` | info | 大部分装备（404%探险者之剑等） |
| 3 | 🟢 绿 | (146,186,147) | `fyg_colpz03bg` | success | 灵光袍430%（可熔炼）、命师手环502% |
| 4 | 🟠 橙 | (214,182,138) | `fyg_colpz04bg` | warning | 探险者之剑584%（橙装）、复苏战衣450% |
| 5 | 🔴 红 | (211,158,151) | `fyg_colpz05bg` | danger | 陨铁重剑486%（神秘装） |

- **熔炼门槛 = 品质数字 ≥3**（对应游戏"稀有"级别；品质2 返回"至少需要稀有级别的装备才可以熔炼"）
- **熔炼产物固定 = "星铜苹果护身符 随机属性+N"**（与品质/总值无关：品质3灵光袍→智力+2、品质5陨铁重剑→力量+2、425%饮血魔剑→敏捷+2）
- 品质数字与词条颜色（2.1 红黄蓝绿白）是**两套独立体系**（品质2 也可能有红词条；品质3 灵光袍有红词条但底色绿）
- **判定位置**：仓库/沙滩 = icon 文件名 `_N`；身上 = class `fyg_colpzXXbg`（2026-08-10 实测两处一致）

### 2.5 品质数字 × 词条颜色关系（21 件样本，2026-08-10）⭐

| 品质 | 样本 | 平均总值 | 平均词条色分 | 红词条出现 | 黄词条出现 | 神秘率 |
|------|------|---------|------------|-----------|-----------|--------|
| 1（灰） | 2 | 311% | 6.0 | 0/2 | 0/2 | 0% |
| 2（蓝） | 14 | 377% | 9.1 | 4/14 | 6/14 | 0% |
| 3（绿） | 2 | 466% | 10.5 | 2/2 | 0/2 | 0% |
| 4（橙） | 2 | 517% | 16.5 | 1/2 | 1/2 | 1/2 |
| 5（红） | 1 | 486% | 9.0 | 1/1 | 1/1 | 1/1 |

**关系结论：**
1. **品质 = 词条数值上限**：品质越高，词条百分比总和越大（311→377→466→517）
2. **品质 ≠ 词条颜色**：品质2 可有红词条；品质4 可不全红（复苏战衣=黄+蓝+绿）
3. **品质越高出高色级概率越高**：品质1 无红黄 → 品质3 必含红 → 品质4/5 高色级为主
4. **神秘门槛 = 品质4**（概率非必然：584% 品质4 无神秘、450% 品质4 有神秘）
5. **两套体系同源于"品级 roll"**：品质决定基础数值与色级概率，词条颜色在此基础上随机

## 3. 神秘属性（isMyst）

- 游戏显示：`[神秘属性]xxx`（如"削弱对方40%回血回盾"、"每次被攻击都会回复5%自身最大生命值"）
- **神秘效果按装备类型固定**（calculator 源码 MYST_ 标志）：
  - 陨铁重剑 → 必暴击（`MYST_CLAYMORE`）
  - 幽梦匕首 → 叠攻速（`MYST_DAGGER`）
  - 旅法师的灵光袍 → 护盾相关（`MYST_CLOAK`）
  - 荆棘盾剑/剑盾 → 反伤+吸血（`MYST_SHIELD`）
  - 复苏战衣 → 回血（`MYST_WOOD`）
  - 彩金长剑 → 真伤（`MYST_COLORFUL`）
  - 海星戒指 → 舞专属（`MYST_RING`，舞增伤）
  - 猎魔耳环 → 技能率（`MYST_HUNT`）
  - 折光戒指 → 攻速+暴击（`MYST_REFRACT`）
  - 凶神耳环 → 雅专属（`MYST_FIERCE`）
- **神秘等级影响远大于装备影响**（帖子共识）；同神秘等级间角色有优劣势

## 5. 数值公式与评分

### 5.1 词条数值公式（帖子+源码确认）

```
词条数值 = 装备等级 × 词条百分比（简单乘算）
```

- 例：Lv.100 装备，词条"附加物伤 125%" → 附加物伤 125
- 不同词条有各自的等级系数（源码 `preparePcBStat` 各 GEAR_ case 不同公式，如剑 = lvl×10×percent）

### 5.2 装备评分（脚本用）

```
评分 = 4 词条百分比之和（词条总值）
橙装 = 总值 516%-585%（无脑收）
熔炼资格 = 总值 ≥410% 且品质 ≥稀有（2026-08-10 修正：418% 普通品质实测不可熔，返回"至少需要稀有级别的装备才可以熔炼"）
```

### 5.3 装备选择原则（帖子共识）

- **看需要的词条数值（等级+品质），不是看颜色**——绿装关键数值可能比橙装高
- 用计算器（guguzhen-calculator）对着算，词条分布比颜色重要
- 装备满级 300，锻造/开箱建议等争夺等级 300 后再造

## 6. 装备处理规则

### 6.1 拾取（沙滩→仓库）
- `c=1&id=<沙滩装备id>`（stpick）；重复拾取返回"卡片不存在"
- 橙装（≥516%）**无脑收**（其他角色可能适用）

### 6.2 熔炼（装备→护身符）
- `c=9&id=&yz=124`（pirl）；**成功返回新护身符 id**
- 熔炼资格：词条总值 ≥410% **且品质数字 ≥3**（2026-08-10 实测：品质2→"至少需要稀有级别的装备才可以熔炼"）
- **熔炼产物固定 = "星铜苹果护身符 随机属性+N"**（与装备品质/总值无关）→ **神秘装/橙装永不熔炼（巨亏）**
- 护身符 = 水果+金属命名（如"星铜苹果护身符 敏捷+2"），属性 = 六维点（力/敏/智/体/精/意，Max 80）或百分比（Max 10%）

### 6.2b 护身符佩戴/摘下/存储（2026-08-10 完整实测）⭐⭐
- **未佩戴护身符在仓库 = 占仓库格**（仓库 35 格含护身符）
- **佩戴** = `c=22`（puto，仓库详情 ca=2 弹窗"放入我的饰品栏"）→ 护身符移入饰品栏**不占格**，属性生效
- **摘下** = `c=21`（puti，饰品栏详情 ca=1 弹窗"放入仓库 (将不会起效)"）→ 护身符移回仓库占格
- **饰品栏 = 8 槽**（`fyg_equip.php` 页面底部"我的饰品"区），同类属性**叠加生效**（2 个智力+2 = 智力+4）
- ⚠️ **护身符 id 佩戴/摘下都会变化**（**已验证非混淆**，用唯一属性力量+2 对照实验 2026-08-10）：
  ```
  力量+2：仓库 14707980 → 佩戴(c22) → 饰品栏 15809819 → 摘下(c21) → 仓库 14708066
  （智力+2 同样：14708020 → 15809803 → 14708067）
  → 每次佩戴/摘下服务器都分配新 id，脚本必须每次操作后重新抓取 id
  ```
- ⚠️ **装备穿脱 id 同样会变**（2026-08-10 用户手动换装证实：萌爪耳钉 14692639 → 14708013）→ **所有装备 id 都不能长期缓存**，每次操作前重读 f=2
- 饰品栏护身符按钮：`zbtip('<id>','1')`（ca=1 详情）；仓库护身符：`zbtip('<id>','2')`（ca=2 详情）

### 6.3 分解（沙滩清理）
- `c=20`（sttz）沙滩全部装备 → 锻造石：`蓝锻造石 x N 绿锻造石 x N`
- 分解产出只与**装备等级**挂钩（越接近 300 越容易 +5；250 以下无价值）
- **锻造石未实装**（2026-01 帖子确认），清理主要为了腾位置

### 6.4 强化
- **装备强化未实装**（按钮无效，花架子）
- **护身符可强化**：`c=23&id=<护身符id>`（qhhsf），6 万贝壳/次，增强或增加一条随机属性（百分比属性单次强化可能 <1% 只加隐藏分）
- ⚠️ 护身符强化是**主动投资行为**（烧贝壳），类似锻造/许愿，**不属于每日流程**，仅在需要时手动执行
