## 可研究方向（2026-08-16 从回复提取）

### ⭐ 高价值研究点
1. **打人不打野**（zerostar 建议）——**✅ 已实测（2026-08-16）**：
   - CC 段打人（`fyg_v_intel.php id=2`）**连续 3 次全轮空**："随机对手近日无胜场，不计出击次数，请重试"（29 字节）
   - **轮空不计出击次数、零损失**；但 CC 段玩家活跃度低 → 匹配不到对手
   - 结论：低段位（CC/CCC）打野仍是主要选择（CC 打野稳赢 +1%）；zerostar 建议可能更适合**人多的段位**（B 段+）
   - 打人胜利 +3% 比打野 +1% 划算，但前提是能匹配到对手——当前段位不可行
2. **翻牌倍率公式**——**✅ 已验证（2026-08-16）**：`收益 = 基础值 × (1 + 段位进度×0.3)`，100% 进度 = 1.3 倍
   - 实测对照：08-12（CC 92% 3幸运）= 8929 ≈ 7000 × (1+0.92×0.3) = 8932 ✅
   - 08-13（CC 92% 3史诗）= 10714 / 1.276 ≈ 8397 ≈ 幸运基础值 × 1.2（史诗 > 幸运）
   - 08-11（CCC 2.5% 3传说）= 7441 < CC 92% 幸运 → **进度加成主导，高于段位影响**
   - 结论：**高进度时翻牌收益显著**（92% 进度 ≈ 1.276 倍）；日常应先把进度打高再翻牌
3. **橙/红装备分界线**：总值 ≥515(525?) 橙、≥585(595?) 红（与现有 516/585 记录吻合，可微调）。**神秘与颜色无关，白装也出** → 熔炼判定"无神秘"条件需复核（白装含神秘时 ③ 能熔炼规则是否仍适用？）
4. **装备品质上限公式**：装备保底 100 最高 300，上限根据总争夺等级（hhao123）。→ 05 文档装备公式可补充。
5. **工坊角色等级 bug**：两年未修，无解，只能等 → 文档标注为已知 bug，不再深挖。
