## 每日检查流程

```powershell
# 查回复（楼层数 + 最新回复内容）
py tools/forum_post.py check --tid 1083618 --sf 267

# 有回复后，回帖（正文写文件，避免参数编码问题）
py tools/forum_post.py reply --tid 1083618 --sf 267 --content-file 回复正文.txt
```

> ⚠️ sf 绑定会话：脚本 check/reply 在**自己会话内**会重新拿 verify，直接用上面的 sf 即可读；
> 若某天 check 报 sf 失效/重定向首页，先用搜索接口在本会话重新解析该帖 sf（见 网站api资料.md §3.3/§3.6）。

- **翻牌**：奖励与段位相关，**横跳时尽量在高段位翻牌**；结果不可控不必纠结。
- **神秘词条**：与装备品质(橙/红)+词条总%有关，神秘换算占 100（满配 500，分界线不详）。
- **锻造**：**争夺 300 级后再锻造**才能出满级装；前期别太勤，约每 +50 争夺锻 1-2 件主装（仅限沙滩不出可用装时）。
